Steps to Use the Tool

Select the file:** Click **Browse** and choose the `.EXE` or `.DLL` file.

Enter the name:** In the **Custom Obfuscation Name** box, enter the name you want the tool to use.

 Enter the Output name:** Enter the name you want for the new file in the **Output Name** box.

 Click Build:** Click **Build** to start the Obfuscation process and change the internal names.
Save the file:** When the process is finished, choose where you want to save the new file.

Result:** A new file will be created with the modified names, while the original file will remain unchanged.
